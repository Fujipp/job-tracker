# First Move

ภาษาไทย | [English](README.md)

First Move คือเว็บติดตามการสมัครงานแบบ private และ local-first ที่สร้างด้วย Nuxt รวมบอร์ดสถานะการสมัคร หน้าค้นหางาน การเตือนติดตามผล สถิติการตอบกลับ และระบบสำรองข้อมูล JSON ไว้ในที่เดียว

## ความสามารถหลัก

- ติดตามงานผ่านสถานะ `Saved`, `Applied`, `Responded`, `Interview`, `Offer`, `Rejected` และ `Withdrawn`
- ย้ายการ์ดด้วยการลากและวาง หรือเลือกสถานะจากการ์ดโดยตรง
- มีสถานะ `Responded` สำหรับกรณีบริษัทตอบกลับ ขอข้อมูลเพิ่ม หรือส่งแบบทดสอบ แต่ยังไม่ได้นัดสัมภาษณ์
- แสดงจำนวนงานที่ติดตาม จำนวนใบสมัคร งานที่กำลังดำเนินการ อัตราการตอบกลับ และเวลาเฉลี่ยก่อนตอบกลับครั้งแรก
- เตือนเมื่อใบสมัครที่ยังดำเนินการไม่มีความเคลื่อนไหวเกินจำนวนวันที่กำหนด
- ค้นหาและกรอง Pipeline ตามคำค้น แพลตฟอร์ม รูปแบบการทำงาน และวันที่
- ค้นหางานจากแหล่งข้อมูลสดสูงสุด 6 แหล่งตามภูมิภาคที่เลือก
- เปิดผลค้นหาทางการของ JobsDB ด้วยตัวกรองที่ใกล้เคียง
- Import และ Export ข้อมูลสำรองแบบ JSON ที่มีเวอร์ชันและผ่านการตรวจสอบ
- Sidebar ย่อ–ขยายได้ รองรับหลายขนาดหน้าจอ และจำค่าที่เลือกไว้ในเบราว์เซอร์

## วิธีใช้งาน

### Pipeline

1. กด **Add opportunity**
2. วาง URL ของประกาศงาน แล้วกรอกตำแหน่งและชื่อบริษัท
3. เมื่อส่งใบสมัครแล้ว ให้ย้ายการ์ดไปที่ **Applied**
4. ใช้ **Responded** เมื่อบริษัทตอบกลับ ขอข้อมูลเพิ่ม หรือส่งแบบทดสอบก่อนนัดสัมภาษณ์
5. ย้ายการ์ดต่อไปตามความคืบหน้าของการสมัคร

ส่วนแจ้งเตือนจะแสดงใบสมัครที่ยังดำเนินการและไม่มีความเคลื่อนไหวนานกว่าค่าที่ตั้งไว้ใน **Settings** การบันทึก Follow up จะเริ่มนับระยะเวลาใหม่

### Discover

หน้า Discover สามารถรวมงานจากแหล่งข้อมูลต่อไปนี้:

- ไทยมีงานทำ — กรมการจัดหางาน
- Job Opportunities API
- Jobicy
- Remote OK
- Remotive
- Remote Landers

แหล่งข้อมูลที่ใช้จะแตกต่างกันตามภูมิภาค ระบบเก็บผลลัพธ์ไว้ในหน่วยความจำ 15 นาที และปุ่ม **Refresh** ใช้ขอข้อมูลใหม่ ส่วน JobsDB ไม่มี public search API สำหรับผู้สมัคร จึงเปิดหน้าค้นหาทางการของ JobsDB แทนการดึงข้อมูลเข้าระบบ

ประกาศงานภายนอกอาจมีการเปลี่ยนแปลงหรือหมดอายุ ควรตรวจสอบตำแหน่ง เงินเดือน สถานที่ และวิธีสมัครจากต้นทางทุกครั้ง

## ข้อมูลในเครื่องและความเป็นส่วนตัว

ข้อมูลการสมัครงานถูกเก็บไว้ที่:

```text
data/job-tracker.json
```

ไฟล์นี้ถูกยกเว้นจาก Git สามารถเปลี่ยนโฟลเดอร์จัดเก็บได้ด้วย:

```bash
JOB_TRACKER_DATA_DIR=/absolute/path/to/data npm run dev
```

Pipeline ไม่ต้องมีบัญชีผู้ใช้และไม่ส่งข้อมูลการสมัครที่บันทึกไว้ไปยังฐานข้อมูลบนระบบอื่น แต่หน้า Discover จะเชื่อมต่อไปยังผู้ให้บริการประกาศงาน และปุ่ม **Get details** จะขอ metadata จาก URL ที่ผู้ใช้ระบุ

โปรเจกต์นี้ออกแบบมาสำหรับผู้ใช้คนเดียวบนเครื่อง หากต้องการเปิดผ่านเครือข่ายหรือเผยแพร่สู่สาธารณะ ควรเพิ่มระบบยืนยันตัวตนและพื้นที่จัดเก็บถาวรก่อน

## การสำรองข้อมูล

- **Export** ดาวน์โหลดงานทั้งหมด การตั้งค่า ประวัติสถานะ และรายการ Discover ที่ซ่อนไว้เป็น JSON
- **Import** ตรวจสอบไฟล์และแสดงจำนวนรายการใหม่ รายการที่อัปเดต และรายการซ้ำก่อนเขียนข้อมูลจริง
- ควรเก็บไฟล์สำรองเป็นความลับ เพราะ Notes และประวัติการสมัครอาจมีข้อมูลส่วนตัว

## โครงสร้างโปรเจกต์

```text
assets/css/          Global styles และ design tokens
components/          Logo, Sidebar, การ์ดงาน และฟอร์ม
pages/               หน้า Pipeline และ Discover
public/              ไฟล์แบรนด์แบบ static
server/api/          API สำหรับงาน การค้นหา การตั้งค่า Import และ Export
server/utils/        ระบบจัดเก็บข้อมูล JSON ในเครื่อง
shared/              Types, schemas และ job utilities ที่ใช้ร่วมกัน
tests/               Unit tests
```

## Production

```bash
npm run build
node .output/server/index.mjs
```

ใน Production ควรกำหนด `JOB_TRACKER_DATA_DIR` เป็นโฟลเดอร์ถาวรที่เขียนข้อมูลได้ ระบบ JSON เริ่มต้นไม่เหมาะกับ serverless deployment หรือการรันหลาย instance
